# Changes

Modified for the generic core distribution: explicit local inputs, conservative
message attribution and native-ID reconciliation, plugin hooks, synthetic demo,
metadata-only doctor, offline defaults and optional user CLI summaries.

Personal integrations and the former web application are retained separately.

Core and private extension contracts have synthetic regression coverage. Private
legacy behaviour is preserved separately; operational migration is an owner decision.

Synthetic executable fixtures resolve platform tools so Linux and macOS use
their actual locations. The macOS machine test identified this portability fix.

Release documentation includes a synthetic issue report template, an explicit
limitations heading and exact commands for an existing verification environment.

Public name: daybook. Install distribution daybook-core from the GitHub source
with uv; the unrelated PyPI daybook package is not this project. README now
credits Prime Radiant prominently and describes the derivative changes.
Upstream LICENSE and NOTICE remain unchanged; release evidence records the
owner disposition for exactly three upstream wording variants.

Stranger feedback fixes: surface reported test contradictions and missing commit
corroboration, prioritize explicit human requests, use checked-out worktree branches
and commit branch membership, refuse unsupported Windows startup, normalize
symlinked demo paths in safety tests, avoid slots for missing model CLIs, provide
safe actionable errors, remove empty brief fields and generic no-upstream push
suggestions, and document neutral synthetic demos and uv installation behavior.

Third feedback round: preserve configured missing-root spelling in doctor, route
each transcript turn by its current checkout, retain rule matches for all-window
handoff contradictions, derive commit-only worktree details from git and include
detached HEAD commits. Ambiguous cached native versions cannot invent edit order
from a last duplicate; equivalent copies retain available handoff text. New demos
use only a neutral synthetic author. Document platform scope and CLI exit codes.

Streamed native messages now follow physical order within each transcript: final text
supersedes intermediate chunks and stale mirrors. Unordered disagreements between
files retain an explicitly marked assistant handoff without crediting user text.
JSON run results include content-free partial-reason codes, including missing CLIs.
Synthetic regressions cover stream order, cold-state permutations, rewrites and routing;
expected negative-test diagnostics are captured and checked without polluting suite logs.
