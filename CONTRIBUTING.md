# Contributing

Use Python 3.11+ on Linux or macOS. Run the README's synthetic quickstart, then
`python -m unittest discover -s tests -q` in one process. Use invented repositories
and JSONL data; never add real transcripts, paths, handles, credentials or personal
config. Keep tests offline, inject fake model/source adapters and use a fresh scratch
folder. Do not add automatic networking or schedules. Document source coverage,
authorship uncertainty and platform limits. Preserve LICENSE/NOTICE and mark changed
derivative files. Contributions are under Apache-2.0 unless explicitly agreed otherwise.
